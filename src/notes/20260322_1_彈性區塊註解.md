要暫時停用一段程式碼，多數人會逐行加 `//`，但要恢復的時候再一行一行刪。

```ts
// const result = await fetchData()
// processResult(result)
// setData(result)
```
---

分享一個我經常使用的註解方式（不限語言）：

## 啟用狀態

```ts
//* <- 單行註解
const result = await fetchData()
processResult(result)
setData(result)
//*/ <- 本身是單行註解
```

第一行因為先判斷了註解符號　`//` 而讓整行都是單行註解，`/*` 沒有作用。
所以中間的程式碼完全正常執行。
最後一行 `//*/` 同理，`*/` 被 `//` 吃掉，當成註解內容，所以不會出現只有單邊`*/`的語法錯誤。

---

## 停用狀態

如果把第一行 `//*` 變成 `/*`，多行註解正式開啟。

```ts
/*  <- 多行註解
const result = await fetchData()
processResult(result)
setData(result)
//*/ //<- 會去讀取多行註解的尾部
```

最後一行 `//*/` 在區塊註解裡面，`//` 沒有意義，`*/` 才是有效的，剛好把整塊關起來。

---

所以就能達到第一行加或拿掉一個 `/`，切換是否跑該段程式的效果，既讓註解不會看起來太亂。
